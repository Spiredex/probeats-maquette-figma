# probeats-maquette-figma
Maquette Figma du site e-commerce Probeats

Le fichier Figma contient :

- La page d'accueil en maquette desktop et mobile
- La page Produit en wireframe desktop et mobile
- La page Commande en wireframe desktop et mobile
- La page A propos en wireframe desktop et mobile
- La page Assistance en wireframe desktop et mobile
- Les styles graphiques
- Les composants réutilisables
- Le prototype permettant de visualiser l'enchaînement des écrans

## Charte graphique

Police utilisée : Barlow

Couleurs :
- #292A2D
- #009099
- #41B4B8
- #7EDCE1
- #B6A299
- #FFFFFF

## Prototype

Le prototype présente les parcours principaux :

- Accueil vers Produit
- Produit vers Commande
- Accueil vers A propos
- Accueil vers Assistance
- Accueil vers Panier / Commande

## Livrable

Le livrable principal est le fichier :

`Probeats - Maquette e-commerce.fig`
